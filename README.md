# Life Archive

**Multi-generational family legacy preservation platform**

## Quick Start

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Stack

- **Frontend**: Next.js 14, React 18, TailwindCSS
- **Backend**: Supabase (PostgreSQL)
- **Storage**: Cloudinary
- **Deployment**: Vercel
